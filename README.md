# Shadowrocket 个人配置

将 [Shadowrocket.conf 的 Raw URL](https://raw.githubusercontent.com/shinelinxx/shadowrocket-personal/main/Shadowrocket.conf) 添加到小火箭的「配置」页。

在 GitHub 编辑 Shadowrocket.conf，在 `[Rule]` 开头添加个人规则，然后在小火箭点「更新」。本机临时规则可以继续放在本地模块。此仓库公开，节点、订阅链接、账号信息和内部域名请只留在本机。

主配置以 [LingJingMaster/Shadowrocket-Rules](https://github.com/LingJingMaster/Shadowrocket-Rules) 为基础，原有远程规则集继续引用原地址。作者的主配置如果改了策略组或规则顺序，需要手动合并到本仓库并保留个人规则及本仓库的 `update-url`。
